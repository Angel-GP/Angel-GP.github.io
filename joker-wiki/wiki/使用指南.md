# 使用指南

本 Wiki 是**纯前端应用**，托管在 GitHub Pages，内容存放在本仓库 `joker-wiki/wiki/` 目录的 Markdown 文件中。页面通过 GitHub API 直接读写这些文件，每次保存都是一次 Git 提交。

## 一、部署位置

本 Wiki 已部署在 **`Angel-GP/Angel-GP.github.io`** 仓库的 **`joker-wiki/`** 子目录，与仓库里原有的网站互不干扰。

- 访问地址：<https://angel-gp.github.io/joker-wiki/>
- 页面内容文件：仓库 `joker-wiki/wiki/` 目录下的 Markdown 文件
- 修改内容提交推送后，GitHub Pages 会自动重新发布（约 1 分钟生效）

## 二、配置编辑 Token（推荐）

不配置 Token 也能正常浏览和搜索，但**编辑 / 新建 / 删除需要 Token**。

1. GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token
2. Repository access 选择**仅本仓库**
3. Permissions → **Contents** → 选 **Read and write**
4. 设置合理的过期时间，生成后复制 `github_pat_...`
5. 回到本站 → 侧边栏右下角 **⚙ 设置** → 粘贴 Token → 保存

> ⚠️ Token 只保存在你**当前浏览器**的 localStorage 中，不会上传到任何服务器。请勿在公共电脑上配置 Token，并记得设置过期时间。

## 三、编辑与双链

- 右上角 **✏️ 编辑** 进入编辑器，`Ctrl+S` 或点「保存」即写入仓库
- 用 `[[页面名]]` 引用其他页面，例如 [[Home]]；不存在的页面显示为**红色虚线**，点击即可创建
- 支持 `[[页面名|自定义文字]]` 别名语法
- 新建页面时路径可用 `/` 建子目录，如 `前端/React`

## 四、其他功能

- **搜索**：侧边栏输入关键字实时过滤标题；勾选「全文搜索」后回车搜索正文
- **历史**：右上角 🕘 查看最近 30 次提交，可查看旧版本或恢复到编辑器
- **反向链接**：右上角 🔗 查看哪些页面引用了当前页
- **目录**：正文标题自动生成右侧目录（桌面端）
